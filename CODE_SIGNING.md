# Code Signing Policy

Free code signing provided by [SignPath.io](https://signpath.io/), certificate by [SignPath Foundation](https://signpath.org/).

## Scope

This policy applies to official OpenAlice Windows Desktop releases published from [`TraderAlice/OpenAlice`](https://github.com/TraderAlice/OpenAlice).

## Build & Origin

Official Windows installers are built on GitHub-hosted runners from `TraderAlice/OpenAlice` release commits and submitted to SignPath with GitHub Actions origin verification.

## Team Roles

- **Committers & Reviewers**: [`@luokerenx4`](https://github.com/luokerenx4) (`TraderAlice/OpenAlice` maintainer)
- **Approvers**: [`@luokerenx4`](https://github.com/luokerenx4) (SignPath organization administrator; manually reviews and approves signing requests in the SignPath UI)

## Privacy Policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
