# Desktop app icon

`icon-source.png` is the unmodified community artwork supplied to the project
maintainer on 2026-09-23. The packaging assets use that image scaled to 1024 px
with a 210 px rounded transparent corner mask; the character itself is not
redrawn. `icon.png` is the common source for `icon.icns` (macOS) and `icon.ico`
(Windows, with 16–256 px representations). Keep all three packaging formats in
sync when replacing the artwork.
