Create a Project, ingest clean OHLCV market bars, and iterate causally on the Validation split before touching Holdout.

1. Create Project & Splits 
uv run aq project create . us-momentum --name "US Momentum"
uv run aq project set-splits . --project us-momentum \
  --train-end 2022-12-31 --val-end 2024-06-30 --holdout-end 2025-12-31
2. Ingest Market Bars 
uv run aq data ingest . --project us-momentum \
  --source prices.csv --dataset-id equities-1d
3. Record Runs in Python 
import autoquant as aq
panel = aq.load_panel("projects/us-momentum", split="val")
mom = panel.pivot(index="timestamp", columns="asset", values="close").pct_change(20)
aq.evaluate_factor(mom, panel, project="projects/us-momentum", name="mom-20d")
