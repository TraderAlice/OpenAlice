# Office operations-journal assets

These generated RGBA PNG badges give the live runtime log four stable game
categories while all event facts and actions remain DOM-owned and accessible.

- `lifecycle-v1.png` — Session and runtime lifecycle events
- `message-v1.png` — assistant text events
- `tool-action-v1.png` — tool execution events
- `alert-v1.png` — rejected, failed, and error events

The built-in image generator used `docs/assets/office/style-master-v1.png` as a
strict visual reference. Each prompt requested one transparent, centered,
late-GBA 16-bit UI badge in the charcoal, cream, teal, cyan, and brass Office
palette, with no text, people, logos, watermark, or background scene. Repository
copies are alpha-cropped, square-padded, and nearest-neighbor scaled to 96 px.
